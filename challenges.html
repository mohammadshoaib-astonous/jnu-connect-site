Module 03

Extra Challenges

Finished the core build? Extend JNU Connect on your own — at home, or in the time left today. These aren't required, but they'll teach you what comes next.

Easy

Add a Faculty object

If you skipped it during the main build, add the Faculty object now with a Lookup to Department. Link a few faculty members to your CSE department.

Easy

Build a second List View

Create a view showing only PG programs, or only students enrolled in the current year.

Medium

Add a Report and Dashboard

Build a report like "Students by Program" or "Students by School," then place it on a simple Dashboard with a chart.

Medium

Assemble a Lightning App Page

Use App Builder to drag a List View, a Chart, and a Rich Text welcome banner onto one home page for JNU Connect.

Medium

Add a second Approval step

Extend the Approval Process so a rejected application can be resubmitted with updated information, instead of being a dead end.

Hard

Add a Scholarship object

Create a new object linked to Student, tracking scholarship applications. Route it through its own Approval Process with a different approver — the Director instead of the HOD.

Hard

Expand the Agentforce agent

Add a third Topic that lets a student ask "What scholarships am I eligible for?" — grounded in the Scholarship object above.

Hard

Build an Experience Cloud portal

Give students their own limited-access login where they can view only their own Student record and enrollment status — a real look at how external users interact with Salesforce.
